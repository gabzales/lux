# Audit keamanan & egress — vipluxzco (2026-10-07)

Cakupan: `server.js`, `supabase.js`, `genspay.js`, `ghostseller.js`, `dripstore.js`, `httpjson.js`, semua `views/`, `vercel.json`, `.env.example`, SQL.

## Hasil yang baik (tidak perlu diubah)
- Tidak ada `.env`, service-role key, token provider, atau key lisensi hardcoded di zip. `database/` kosong.
- Key produk di-strip dari semua view/API publik (`withStockCount`, `/buy/:id`, `/api/products`). Tidak ada `process.env` / service-role yang masuk ke EJS/JS frontend.
- `check-payment` sudah cek kepemilikan (anti-IDOR). Webhook GensPay: signature diverifikasi `timingSafeEqual`.
- RLS aktif + `REVOKE` dari anon/authenticated. Kode order memakai `crypto.randomInt` (32^8 ≈ 1,1×10^12).
- Rendering testimoni/toast di frontend sudah di-escape (`escapeHtml` / `textContent`).

## Belum dikerjakan (butuh keputusan / migrasi lebih besar)
1. **Key produk disimpan di dalam `products.json`** → setiap cold start & refresh cache menarik semua key walau cuma untuk menampilkan katalog. Perbaikan benar: pisahkan key ke koleksi sendiri (mis. `keys:<productId>`) — perlu migrasi data.
2. **`initializeDB` memuat SEMUA koleksi tiap cold start** (termasuk seluruh transaksi). Idealnya transaksi tidak ikut di-preload.
3. **Kredensial PakKasir & Fonnte tersimpan di database** (hanya dimasker di UI). Lebih aman di env Vercel seperti GensPay/Ghostseller/Drip Store.
4. `/invoice?code=` menampilkan key hanya berbekal kode order (by design). Entropi kode cukup; jangan pernah membagikan kode order ke publik. `Referrer-Policy` sudah dibatasi.
5. `requireAdmin` fail-open bila Supabase error saat cek lock (sesi admin sudah valid saat itu). Tidak ada CSRF token (mitigasi: cookie `sameSite=lax`).
6. `/__build` publik membuka versi & commit SHA; `stockCount=999999` menandakan produk memakai auto-restock provider.

## Yang tidak bisa diverifikasi dari sini
- SQL RPC hanya divalidasi sintaks (parser Postgres) dan perilakunya disimulasikan; belum dijalankan di Supabase asli.
- Format respons PakKasir asli, Turnstile live, dan webhook GensPay asli tidak diuji.

## Perbaikan susulan
- Layar hitam setelah tombol Back: `layout.ejs` mem-fade body ke `opacity:0` saat klik link dan tidak pernah mengembalikannya saat halaman dipulihkan dari cache browser. Ditambah handler `pageshow`; ctrl/cmd-klik tidak lagi dibajak.
- Gambar produk kosong: `/images/placeholder.jpg` dirujuk server tapi file tidak ada; upload gagal ke Supabase Storage ditelan diam-diam (produk tersimpan "sukses" tanpa gambar). Sekarang bucket `product-images` dibuat/dipublikkan otomatis, URL publik diverifikasi, error asli ditampilkan ke admin, dan placeholder tersedia.
